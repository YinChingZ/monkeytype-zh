# Monkeytype 中文释义

Chrome / Edge 扩展，在 Monkeytype 练习时显示当前英文单词的中文释义和音标。当前版本：**1.1.0**。

## 安装

1. 下载本仓库 ZIP 并解压，或克隆仓库。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。
4. 打开或刷新 [Monkeytype](https://monkeytype.com/)，选择英文练习。

无需构建、API Key 或联网翻译。扩展未上架商店；安装后请保留该目录。更新文件后，先在扩展管理页点击「重新加载」，再刷新 Monkeytype。

## 功能

- 内置 399,462 条英文词条及补充词形，按首字母加载并缓存。
- 随当前单词更新，处理大小写、两端标点和额外误输入。
- 支持 tape mode 的 word / letter 模式。
- 默认跟随网站主题和字体；可选择独立浅色、深色和字体。
- 字号可自定义或跟随网站；可调整位置、对齐、偏移、间距、宽度和释义行数。
- 背景、边框、阴影分别开关，支持背景透明度和纯文字显示。
- 设置即时生效并保存在本机，支持重置外观。

点击浏览器中的扩展图标打开设置，向下滚动可查看全部选项。

## 使用范围

适用于普通英文、英文引文和英文自定义文本。释义来自词典，不是整句语境翻译。未收录词会显示提示。Zen 模式以及改变原文或隐藏文字的特殊 Funbox 未保证支持。

位置受窗口边缘限制，练习区上方或下方空间不足时自动换边。字号同步限制为 12–48px。中文使用可用的系统字体补全。自定义图片背景或低不透明度下，可读性仍取决于底图。

依赖 Monkeytype 当前的 `#words .word.active` 页面结构，网站更新后可能需要适配。

## 隐私

仅声明 `storage` 权限，内容脚本仅在 Monkeytype 域名运行。查词完全离线，不上传单词、账号、成绩或输入历史，无遥测和远程代码。本机仅保存显示设置。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 浏览器扩展入口及权限 |
| `content.js` | 当前单词识别、释义展示和外观同步 |
| `background.js` | 离线词典查询 |
| `settings.js` | 默认设置和输入校验 |
| `popup.html` / `popup.css` / `popup.js` | 设置界面 |
| `dict/` | 按首字母拆分的词典和来源信息 |

普通 JavaScript，无构建依赖。可用 `node --check 文件名.js` 检查脚本语法；加载扩展后检查切词、退格、重启、外观切换与 tape mode。此前版本在 Chromium 中做过上述浏览器验证；全部特殊练习模式尚未逐项验证。

## 词典来源与许可
